# 自动阅读助手 · 自动滚动（Chrome 扩展）

一个用来「解放双手」的阅读扩展：页面自动向下滑动，滑动速度随时可调，读完自动进入下一章。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本文件夹（`auto-reader-extension`）。
4. 打开任意小说 / 文章页面，右上角工具栏点击「自动阅读助手」图标，点「开始滚动」即可。

## 功能

- **自动识别正文页**：按 `article` / `main` / 常见正文容器、文字长度、段落数、标点密度、链接占比、`og:type` / JSON-LD 等信号打分，只有通过识别的页面才显示悬浮控制条；首页、列表页、搜索页不会出现。
- **自动向下滑动**：按像素速度匀速滚动，速度 2–120 px/s 任意调节，面板上同时给出「≈ 字 / 分钟」估算。
- **页面悬浮控制条**：页面右侧的竖条可以直接 ▶ / ❚❚ 开始暂停、加减速度，点 ⚙ 展开完整设置；可以拖动到任意位置，鼠标移上去自动暂停。
- **快捷键**
  - `Alt + S` 开始 / 暂停
  - `Alt + ↑` 加速（加 Shift 一次 +50）
  - `Alt + ↓` 减速
  - `Alt + T` 回到页面顶部
- **到底自动下一章**：检测页面底部并自动点击「下一章」，切换前有 3 秒倒计时，可以点「取消」。
- **换章后自动继续**：点进新章节后自动接着滚，适合连续性阅读。
- **手动接管**：滚轮 / 触屏 / 翻页键操作时自动暂停 1.3 秒，不跟你抢滚动。
- **进度与时长**：控制条实时显示阅读进度百分比和本页预计剩余时间。
- **显示 / 隐藏控制条**：弹窗里的按钮可在「显示控制条」和「隐藏控制条」之间切换，再次点击即可恢复。

## 速度建议

| 速度 | 大约的阅读节奏 | 体感 |
| --- | --- | --- |
| 4–6 px/s | ≈ 250–350 字/分 | 精读，逐字看 |
| 10–14 px/s | ≈ 600–800 字/分 | 常规阅读（默认 12） |
| 20–30 px/s | ≈ 1200–1800 字/分 | 快速扫读 |
| 50+ px/s | 2500 字/分以上 | 已读章节 / 找情节 |

> 「字 / 分钟」是按当前页面的文字密度自动估算的，换页面会自动重算；不同网站的排版疏密不同，实际以你看着舒服为准。

## 说明

- 设置通过 `chrome.storage.sync` 保存，换设备登录同一账号也会同步（阅读中状态存在 session 里，浏览器重启后不会自己乱滚）。
- 正文识别在页面加载、内容懒加载和站内无刷新跳转时自动重算；阈值按「正文 ≥ 400 字、得分 ≥ 750、链接密度 ≤ 35%、标点密度 ≥ 2%」判断，纯图片页或极短文章不会显示控制条。
- 适配普通网页（http / https），`chrome://`、扩展商店等受保护页面无法注入脚本。
- 悬浮控制条用 Shadow DOM 渲染，不会和网页自身样式互相干扰。

## 文件结构

```
manifest.json    扩展清单（MV3）
background.js    快捷键命令转发
content.js       自动滚动核心 + 悬浮控制条
popup.html/css/js 工具栏弹窗
icons/           图标
tools/           开发辅助脚本（图标生成、选择器自检，不参与运行）
```
